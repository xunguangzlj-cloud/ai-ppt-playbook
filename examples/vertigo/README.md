# 案例：电影课小组展示《迷魂记》(Vertigo, 1958)

一个完整走通本方法学的真实任务：14 页现场讲述型 PPT，五人分工，围绕罗杰·伊伯特 1996 年影评的"自白说"做三重解读（男性凝视深化 / 男性中心盲区 / 社会维度延伸）。全部页面由 `build.js` 用 [pptxgenjs](https://github.com/gitbrent/PptxGenJS) 代码生成，**原生可编辑对象**，完整讲稿按页写入演讲者备注，尾页附问答锚点与参考文献。

## 运行

```bash
npm install pptxgenjs
node build.js          # 输出 vertigo-slides.pptx
```

## 可选资产（不在仓库中，版权原因）

脚本对图片做了 `fs.existsSync` 守卫：没有资产也能跑，产出纯排版版本；把自备图片放到脚本同级目录约定的路径即可自动嵌入：

| 路径常量 | 内容 | 用到的文件名（示例命名） |
|---|---|---|
| `../vertigo-stills/` | 影片剧照与海报 | `00-电影海报-1958原版.jpg`、`01-酒店绿雾重生-….jpg`、`02-米琪-….jpg`、`03-1958片场-….jpg`、`05-楼梯眩晕-….jpg` |
| `../ref_media/` | 校名图 | `image3.png`（绿色版，浅色页右上角）、`image4.png`(白色版，深色页居中) |

剧照可用逐帧站按 `vertigo-movie-screencaps.com-<帧号>.jpg` 模式定位获取；校名图请使用你所在机构的官方版本。素材版权归原权利人，教学合理使用请自行判断。

## 这个案例展示了方法学的哪些做法

- **论证链先行**：全片围绕"自白说为何成立（B）→ 盲区何在（C）→ 还缺什么（D）→ 技巧如何服务（E）"组织，第 2 页可视化这条链
- **内容导向配色**：深绿取自影片灵魂色（绿色霓虹），红橙取自 1958 原版海报；同心圆环=眩晕母题，只出现在深色首尾页
- **证据纪律**：引文带出处；英文原文进备注；小组自判观点（如"情感虐待"）在备注中明确标注为观点而非原文
- **演讲备注**：讲稿全文按页拆分进 notes，含问答定位
- **防 AI 味**：无装饰色条、无标题下划线、扁平构图、卡片网格限额
- **质检**：LibreOffice 渲染逐页检查 + 独立视觉审查通过
