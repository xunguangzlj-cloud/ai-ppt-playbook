# AI 时代 PPT 制作手册

让每一页成为听众理解工作的一步。本手册把经过调研验证（豆包/扣子产品线、GitHub 高星项目 ppt-master/codex-ppt-skill/PPTist/presenton/banana-slides）和真实任务实战检验过的做法，收拢为一条可执行的流水线。它的四个支柱：**大纲先行**（先确认逻辑再排版）、**样张确认**（先定一页再批量）、**双轨渲染**（可编辑轨与生图轨各司其职）、**审核回环**（自检不合格就返修，绝不静默降级）。

## 0. 先确定使用方式

从用户要求和附件中确认：受众、用途、总页数、时限、模板、是否需要独立阅读。已明确的信息不要重复问。缺少会实质改变成果的信息时简洁询问，同时完成材料整理；可用合理默认的事项，说明假设后直接推进——不要让提问阻塞工作。

- **现场讲述型**：观众听讲为主。屏幕保留观点、关系与证据，解释推导放讲者备注。
- **提交阅读型**：读者不依赖讲者。正文保留背景、方法、条件、来源与局限，理解结论所需的内容不能只躺在备注里。
- **兼用型**：先保证独立阅读和事实完整，再用章节层级、小结与附录分配信息。

用户指定的模板、评分要求、字数、页数优先。N 页含封面与结尾页，除非用户明确另算；不要擅自加页。用户要求与模板约束并存时，先检查能否同时满足（如"感谢页配正文"），只有真实冲突才提出澄清——不能替用户决定删掉哪项要求。

## 1. 五阶段流水线

```
① 澄清 → ② 论证与分镜 → ③ 风格确认 → ④ 生成 → ⑤ 自检交付
```

**① 澄清**：用"沟通契约"六问替代模糊需求——受众是谁/意图是什么/什么可观察变化算成功（audience_outcome）/核心信息是什么/讲述还是阅读/交付后要支持什么（artifact_afterlife）。详见 [storyboard-and-gates.md](references/storyboard-and-gates.md)。

**② 论证与分镜**：从材料建立论证链——问题为何值得解决 → 方法如何回应 → 结果如何检验 → 结论推到哪里。结论缺证据时缩小表述或明示缺口，**不能用版式掩盖证据缺口**。每页写一句"看完应理解什么"（Audience move），推进不了任何内容的页合并或砍掉。按分镜九字段整理每页。

**③ 风格确认**：给出**三个真正不同的完整设计方向**让用户选（禁止摆"稳妥/中间/大胆"的假梯度），每个方向=叙事模式×视觉风格×配色的具体组合。确认后锁定为设计锚点。

**④ 生成**：按双轨选型渲染（见下）。可批量并发生成，但样张必须先被确认；样张的生成方法记录下来，所有后续页面继承同一方法。

**⑤ 自检交付**：代码级检查（溢出/重叠/占位符残留）→ 渲染成图逐页目检（字形/换行/遮挡/越界）→ 修复后复验。只有实际验证过的能力才能声称。

## 2. 双轨选型：一开始就要选对

| | 可编辑原生轨 | 整页生图轨 |
|---|---|---|
| 适用 | 交付、二改、数据汇报、模板约束 | 分享、答辩、视觉冲击、风格统一 |
| 中间表示 | 大纲→元素级结构（代码生成或语义标记） | 逐页提示词→整页图→组装 PPTX |
| 工具 | pptxgenjs / python-pptx / HTML→pptx | 生图模型 + 组装脚本 |
| 可编辑性 | 原生对象，二改无损 | 页面不可编辑；图片→可编辑需"擦底板+重分层"，Beta 级难度 |
| 成本 | 约 1 万 token/页 | 每页一张图另计 |

先问清用途再定轨；两轨互转有损耗。选型细节、各路线的代表实现与取舍见 [routes.md](references/routes.md)。

## 3. 设计系统的硬约束

可编辑轨的页面质量由设计系统兜底：内容导向的三角色调色板（背景/主色/强调，强调色 5–10%）、**防 AI 味清单**（禁装饰色条、禁标题下划线、卡片网格限额、正文左对齐）、CJK 排版纪律（用户机器有的字体、文本框加宽 15%）、图表必须原生可编辑。完整规范见 [design-system.md](references/design-system.md)——生成任何页面前先读它。

## 4. 交付诚实纪律

- 文字、表格、要求可编辑的图表保持原生对象；**不能把大纲、HTML 或整页图片冒充可编辑 PPTX**。
- 动画、特殊字体、外部链接先验证工具能力；不能实现就明说限制，用静态方式承接。
- 只有实际打开/渲染检查过的，才能声称验证过；渲染检查与结构检查各自不能互相替代。
- 不承诺"包过""拿奖"或控制评委提问；交付默认不附校验日志与制作过程。

## 6. 与内容层技能的分工

本技能负责**制作与设计**（怎么做得专业）；`ppt-evidence-design` 类技能负责**内容决策**（论证链是否成立、证据是否真实、来源是否可溯）。两者同时可用时：内容技能定"每页说什么、凭什么"，本技能定"长什么样、怎么生成与交付"。
