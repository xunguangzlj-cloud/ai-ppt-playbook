# 论证、分镜与确认门禁

## 1. 沟通契约六问

动手前回答六个问题（缺省可声明假设后推进）：

| 字段 | 问题 |
|---|---|
| audience | 听众是谁？已经知道什么、关心什么？ |
| intent | 这次展示要达成什么？（可多目的，用散文写清优先级） |
| audience_outcome | 什么**可观察的变化**意味着成功——知道/相信/决定/行动？ |
| core_message | 哪怕别的全忘了，必须记住的一个主张是什么？ |
| delivery_context | 主讲、自读、混合还是录制？场合与时长限制？ |
| artifact_afterlife | 交付后要支持评审、审计、归档还是复用？ |

意图决定大纲义务：Persuade=主张+证据+反方意见；Decide=决策请求+选项+标准+拖延代价；Teach=前置+序列+练习；Mobilize=紧迫+可行+立即行动。逐条检查大纲是否兑现。

## 2. 论证链先行

问题为何值得解决 → 方法如何回应 → 结果如何检验 → 结论能推到哪里。先把这条链接通，再分配页面。口才和模板**不能弥补证据缺口**：目标对不上、结论缺数据时，缩小表述或明确标注缺口与假设。

- 团队成果与个人贡献分开说明（答辩场景的常见失分点）。
- **事实溯源**：外部事实带来源（文件/页码/链接），进对应页备注；编造的演示数据明确标"scenario/示意"，永不冒充事实。
- 区分三种话：来源的直接主张、自己的整合推论、场景演示数据。

## 3. 分镜九字段

每页用九个字段组织（内部表格或简洁文本均可，不为形式填满）：

1. 页码与用途——这页为什么存在
2. **Audience move**——看完/听完这页，观众具体知道了什么（推进不了的页合并或砍掉）
3. 标题——主题标题（对象/方法/流程页）或结论标题（结果/批判页，写有证据支持的发现）
4. 证据与位置——来自哪个文件、页/段、数据记录
5. 屏幕内容——观众需要哪些文字、图、表、关系
6. 讲述或阅读解释——现场讲什么；阅读型哪些解释必须在正文
7. 布局与显示顺序——位置表达哪种关系，强调什么
8. 不确定性与局限——结论条件、缺数据、待核对项
9. 问答定位——追问时回到哪个结果/方法/备份页

## 4. 节奏与强制条款

- 每页标一个节奏标签：`anchor`（封面/章节/结尾）/ `dense`（信息承载）/ `breathing`（低密度停顿）。均匀密度是 AI 均匀卡片感的根源；同密度的连续页必须是有意的子弧线。
- 封面必须有一个来自素材最强主张/数字/隐喻/冲突的**具体钩子**。
- 结尾禁止空"谢谢"页：答辩场景推荐"问题+实际贡献+关键证据+局限"的紧凑总览（供提问时参照），口头致谢。用户指定结尾页时遵从用户。
- 讲述页密度：核心叙述争取约 50 字，接近或超过 100 字时复查用途；这不是硬线，**不可为达标删坐标、单位、条件、局限**，也不可把信息画进图片来规避密度。阅读型不套用此限，但要求完整、可读。

## 5. 确认门禁（分阶段降低返工）

一次成型的返工率远高于分阶段确认。门禁设计：

```
GATE 1 大纲确认：沟通契约+论证链+分镜骨架 → 用户确认
GATE 2 风格确认：三个真正不同的设计方向 → 用户选定
GATE 3 样张确认：1 页代表性样张（优先内容页而非封面） → 用户批准
GATE 4 批量生成 + 自检回环 → 交付
```

- 三方向硬规则：自上而下从已确认的契约推导**三个作为设计就不同**的完整意图；禁止摆"稳妥/中间/大胆"的假梯度——如果三个方向只在字段值上不同，它们就不是三个方案。
- 样张要展示"风格如何适应真实内容页"，不是通用模板页；样张直接存为正式文件名（批准后它就是那一页）。
- 样张批准后，把它的生成方法（后端/模式/参数/提示词来源）记录下来，批量阶段全部继承。
- 每个门禁处等明确确认，不替用户做决定；确认过的事项不重复问。

## 6. 决策例子（检验规则用，不是固定页序）

- **5 分钟现场答辩、8 页、有两组实验数据**：8 页含封面结尾。先建立问题→方法→条件→比较结果→局限的证据链再分配页数。结果图的轴、单位、条件保留在页面；口头解释不复制上屏。没有实测值就不能画结果图。尾页用贡献+证据总览，问答细节进备注；不擅自加第 9 页致谢。
- **无需讲述、10 页商赛作业**：每页可超 100 字，方法依据、比较口径与局限放在读者可见的正文或附录；表格保留全部必要字段，不能用十个口号代替分析；不把 Word 整页缩进 PPT。
- **"每页方法说明"遇上"尾页致谢"**：先检查模板是否允许感谢语配正文，允许就同时满足；只有模板确实禁止正文而用户仍要求时才澄清，不替用户删要求。
