# 实现、中文富文本和交付检查

## 环境优先

先加载宿主的演示技能和依赖发现工具；用其规定的创作方式和检查链路。本技能不保证任意机器已安装PptxGenJS、LibreOffice、浏览器或某个模型。用户要求的引擎与当前环境许可先于项目推荐。

新建常用PptxGenJS；精确模板编辑可用受支持的原生编辑器、模板引擎或局部OOXML处理。python-pptx是一个可能的外部实现，不作为所有模板任务的默认首选，宿主不允许时不得采用。

## 单位和参数

- PowerPoint几何通常为EMU：1英寸=914400 EMU；1pt=12700 EMU。按96 DPI使用像素时1px=9525 EMU，其他DPI不能照搬。
- 字体字号的XML单位为百分之一pt；图形坐标、字体和线宽不可混用。
- PptxGenJS坐标通常用英寸，字号用pt；颜色用6位HEX字符串。填充/图像透明度与阴影透明度采用不同字段和量程，查当前类型定义，不把全部透明度写成`opacity`。
- 独立构造可变样式对象，避免生成引擎改动共享对象后影响下一页。实际写出成功后检查文件；排队的编辑请求不是完成证据。

## 段落与富文本

文字框→段落→run各有不同职责。框控制边距与垂直对齐，段落控制行距与项目符号，run控制颜色、粗体、链接等。整框赋值常会清除原富文本，替换时保留需要的run样式与链接。

同一句中的强调片段保持在同段落，不统一给每个run添加`breakLine`；多个项目符号项才在项之间换段。换行是排版意图，不是颜色片段的附属属性。设置内边距与悬挂缩进后检查实际输出，避免空圆点、双圆点、括号或句号单独成行、姓名拆开、单位与数值分离。

不能只按汉字数估算容量。字体替代、混排标点、粗体和渲染器度量都会改变换行。预留空间并检查导出的PPTX；HTML或SVG预览通过不代表PPTX通过。

## 可运行的包检查

需要Python 3.10+标准库；脚本不安装依赖、不执行文档中的代码，也不修改PPTX：

```text
python scripts/audit_pptx.py final.pptx --expected-slides 14
python scripts/audit_pptx.py final.pptx --compare-source original.pptx --require-same-media
python scripts/audit_pptx.py final.pptx --require-native-table-slide 13
```

脚本检查ZIP CRC、XML可解析性、内部关系目标、按展示顺序的页数及逐页原生对象统计；对照选项检查去除空白后的文字、备注正文和原始媒体哈希集合。对照会忽略纯空白变化，不证明逐字节保留；媒体集合相同也不证明图片出现位置相同。要求特定页的原生表格/图表可用对应选项。

原生对象统计不验证编辑数据的可用性；脚本不检查Schema全部约束、字体嵌入、图表数值、视觉遮挡或原生动画。几何检查优先用宿主工具；逐页出图仍是必要步骤。若宿主有更完整检查器，按其要求执行，本脚本仅补充保留对照。

## 文件与审查版本一致

保存源材料与最终文件的SHA256；记录检查所用成品，而非只记录脚本或中间HTML。改页面后重导出受影响页，共享样式/字体/素材变更时重查所有依赖页。最终交付须与已审查文件一致。目标应用未实际运行时不声称“已在PowerPoint验证”。
