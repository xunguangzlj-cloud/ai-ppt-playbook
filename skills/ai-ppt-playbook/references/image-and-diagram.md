# 配图与图解

## 1. 图片来源决策（逐图决定，不是逐 deck）

| 来源 | 用在 | 理由 |
|---|---|---|
| provided | 用户指定的事实/品牌/产品素材 | 按保留要求使用；附件本身的主张仍需证据核对 |
| web 搜图 | 真实主体必须以真面目出现（地标、人物、产品） | 核对主体、来源与使用条件；不自动声称许可或署名已经处理 |
| ai 生图 | 虚构、风格化、隐喻、装饰字 | 表达力优先于纪实性 |
| placeholder | 素材后补 | 占位需标注 |

硬规则：
- 按信息作用决定是否需要图片，再检查可用素材和工具。已有文字或数据足够表达时不强加图；关键证据图缺失时明确标记，不用无关图片填补。
- 真实主体（城市、建筑、名画、产品）无论整体风格多插画化，都用 web/supplied 保证"以真面目出现"；风格只解决"长什么样"，不解决"是不是它"。
- 网图标注来源，截图保持可辨识。

## 2. 整页生图提示词六件套

逐页生图时可按此组织提示词；这些约束不能保证模型不漏字，必须检查实际输出：

1. **XML 标签分区**：`<page_description>` / `<page_style>` / `<design_guidelines>` 分开装内容、风格、规则。
2. **模板措辞分叉**：有模板参考图 →"配色和设计语言**严格相似**"；无模板 →"严格按照风格描述进行设计"。
3. **防串台**："只参考风格设计，**禁止出现模板中的文字**"。
4. **防漏字**："**不重不漏**地渲染'页面文字'段落中的文本"——漏字/改字是整页生图最大翻车点。
5. **禁 markdown 符号**："如非必要，禁止出现 # 和 * 等格式符号"。
6. **封面特判**：封面页追加"凸显页面标题，分清主次，一下抓住观众"。

配套：4K/高分辨率 + 明确宽高比；多页一致性靠"样张作为 style-only 参考（match style only, do not copy layout）"；用户素材图是 **strict input asset（preserve labels/data/arrows/content）**，两类参考图在交接时明确分权。

提取风格时渲染代表页检查实际外观，同时读取主题、母版、字体和对象结构来核对继承与编辑能力。像素与结构互补，不能只用其中一个证明另一项能力。

## 3. 关系 → 图解（语义驱动，不是目录套用）

六种关系原子，各带生成轴：
`order`（顺序：开/合路径、直/折/阶梯/之字/盘绕、升降平）· `link`（依赖/交换：直连/枢纽/链/分合/反馈，最少必要边）· `parent`（分支/缩进/嵌套/辐射）· `membership`（包围/色带/泳道/簇）· `contrast`（语义轴/对立场/共享基线/前后界）· `overlap`（配对/链式/层叠交）。

三条反直觉硬规则：
- **永不从平衡推断拓扑**：节点数和文字量只能影响间距/绕线，不能成为等形、等距、镜像、放射对称的理由——那会凭空发明对等权重、中心性、互惠性。
- 构建顺序：主干 → 节点 → 连线 → 标签 → 点缀；**移除点缀后所有含义完好无损**才算合格。
- 八项验证里最有效的是**移除测试**：去掉颜色/特效/图标/点缀，仅靠位置和形状仍能沟通，图解才算成立。

装配配方优先描述相对约束（形状身份、语义计数、组件关系），实际创作再根据画布计算坐标。先拆需要独立编辑或动画的组件，再检查共享基准线、接缝、贴合或有意间隙。嵌套层级保持各层独立，不能因合并轮廓丢失可编辑身份；阶段载体也不能遮挡正文。

预设形状的语义纪律：按"这个形状为读者做什么"从完整词表选形，语法简单不是选矩形的理由；名字联想不等于语义匹配（闪电≠价格张力，流程图符号只出现在真流程图）。

## 4. 图表自检回环

导出图片 → 读图检查 → 修复 → 复验。按缺陷和任务规模迭代，不以固定两轮作为完成标准。结构图另核对节点与关系，数据图另核对数值与尺度；修复在产生故障的层进行。
