# 编排纪律：多页生成、状态与质量

页面多了以后，质量问题的根源通常不是"画得不好"，而是**编排失控**：状态不清、静默降级、子代理越权。这份文件是多页/多代理生成时的运行纪律。

## 1. 防降级原则

替代方案是否可用，按原任务的质量与编辑要求判断。数据绘图、受支持的原生形状和必要的图片预处理可以是合格实现；整页截图不能替代用户要求的原生文字与数据图表。引擎不可用时先找满足同一契约的路径并验证；确实无法满足时报告具体缺口，不虚构已完成。用户锁定后端或改变交付能力时才需其选择。

同理适用于交付形式：只能产出大纲时，明确说"尚未生成 PPTX"，不用 HTML 或图片冒充。

## 2. 文件状态机（不认聊天记录）

复杂批量或跨代理任务可用`slide_jobs`记录状态（pending → dispatched → recorded → accepted / blocked）。简单编辑用一份检查记录即可，不为每页强制建立独立作业系统。

- "聊天里说做完了"不等于完成——**完成状态只认脚本/文件记录**。
- 采用逐页作业时，每页一个job文件（提示词、素材映射、继承的样张方法）；结果由脚本写入（输出路径、后端、QA备注）。
- 使用该状态机时，组装前校验所有作业`accepted`，未完成或阻塞的作业不能冒充通过。

## 3. 经授权使用子代理时的分工

默认由当前代理完成。只有用户或环境明确允许委派且任务确实获益时采用以下分工；技能不要求一页一个代理，也不扩大外部写入授权。

- 主代理负责：编排、提示词任务制备、状态记录、QA、演讲备注、最终组装。
- 子代理按独立页面或章节分工，负责：读自己的 job 文件、按继承的样张方法生成、返回固定三行（backend_used / 产出路径 / qa_note）。
- 子代理**禁改共享工件**（大纲、spec、其他页的 job、成品装配）。
- 交接单要素：deck 目录、job 文件路径、输出目标归父级、样张生成方法全套拷贝、两类输入图分权（样张=只匹配风格不抄版式；素材=严格保真数据标签）、不可用时返回 blocker。

## 4. 逐页九步决策链

画第一笔坐标前，每页按序决策一次（在活动上下文中完成，不反复重读文档）：

1. **沟通追踪**——本页推进什么 Audience move？推进不了的页是提纲缺陷，上报而不是硬装。
2. 阅读模式核对——讲述型/阅读型/兼用型决定页面承载。
3. 拓扑决策——页面的语义关系（顺序/依赖/层级/分组/对比/交叠）是否需要几何表达。
4. 节奏标签应用——anchor / dense / breathing。
5. 载体混合——背景、文字、原生几何、图片、图表的组合与权重。
6. 模块声明——本页用到哪些能力，写一行。
7. 构图——版式结构与母题在本页的表达。
8. 几何——形状语言与构图移动。
9. 坐标与边界——先写句子，再划区域，最后定坐标。

权限边界：执行层可改写、压缩、重组、换载体（保持信息等价）；**永不加主张、跨页搬内容、为排版丢信息**。

## 5. QA 回环

三层检查互相不可替代：

1. **代码级**：文字框容量估算、形状越界、遗留占位符（用rg检查）；包围盒相交只是候选问题，背景与文字、有意叠放不能一律判错。
2. **渲染级**：用宿主渲染器或可用的PowerPoint/WPS/LibreOffice逐页出图，检查字形、换行、遮挡、越界、截图清晰度和跨页一致性。无需为使用固定链路强装工具。总览图看节奏，逐页图查细节；再次导出的成品也需检查。
3. **结构级**：文件能重新打开、页数正确、图片关系完整（无 dangling rId）、要求可编辑的内容是原生对象。

发现缺陷在"拥有该故障的最浅层"修复：页面级问题修页面，规划级问题退回 spec，工具问题修脚本——不从下游遮掩上游的病。

记录最终文件哈希、实际检查范围、未解决问题；源页变动使该页审查失效，共享字体/样式/素材变动使所有依赖页失效。修复后只复验受影响内容与最终包，不机械重跑无关检查。

## 6. 交付清单

- [ ] 页数与计划一致（N 页含封面结尾，未擅自加页）
- [ ] 关键结论有对应证据；无证据处标明计划/假设/缺口
- [ ] 阅读型移除讲者仍可理解；讲述型无需念整页
- [ ] 单位、口径、条件、图例、表头、来源齐全；团队/个人贡献清楚
- [ ] 逐页渲染检查完成；要求可编辑的内容为原生对象
- [ ] 演讲备注写入；问答锚点（如有）标明回跳页
- [ ] 动画/特殊字体等未验证能力如实标注
- [ ] 用户原件未被改动（默认另存新文件；确需原地改先备份）
