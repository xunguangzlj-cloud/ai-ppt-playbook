# 数据图表：数值、编码与原生对象

## 先锁定证据

每张图确认来源、时间范围、样本、类别、系列、单位、比较口径和缺失值。记录计算公式及舍入规则；真实测量、估计、目标与演示数据分别标记。仅因缺数据不能自动填一组看似合理的数值。

不要为了美观改变值、顺序或异常点。相同度量的比较面板尽量共享尺度和类别顺序；不同尺度必须可见披露。数据决定几何，不能目测柱长、扇形角度或气泡面积。

## 任务决定图形

| 读者任务 | 常用表达 | 重点检查 |
|---|---|---|
| 比较大小或排名 | 条形/柱形 | 长度表示数量时从零起；保留有意义的类别顺序 |
| 看时间变化 | 折线 | 时间间隔、缺失值与是否断线；非零轴明确且不过度夸大 |
| 看关系 | 散点 | 点对应的样本、两个轴的单位；相关性不自动写成因果 |
| 看构成 | 堆叠条或少量类别的占比图 | 总量、分母、负值、舍入误差和类别覆盖 |
| 看分布或不确定性 | 直方、箱线、区间/误差图 | 分箱、统计定义、区间含义和样本量 |
| 看精确值或多字段 | 表格 | 表头、单位、精度、口径与必要来源 |

直接标签在清楚时可替代图例；所有系列、轴名和单位并非都必须重复，已经清楚呈现的编码不添加无用标签。颜色之外再用标签、符号或线型识别重点，不仅靠红绿表达判断。

## 可编辑性分级

- **数据绑定原生图表**：可改变系列/类别/数值，应校验图表数据及嵌入工作簿。
- **原生形状图解**：可以移动形状与改标签，不等同于可编辑统计数据。
- **矢量或位图**：适合保留复杂科学图和用户原图；诚实说明其编辑范围。

引擎不支持原生误差线或特殊图型时，验证补充系列/OOXML的语义，或保留经验证的科学图。不能用生成模型重绘证据数据，不能把文字可选中当成图表数据可编辑。

## 数值与导出双核验

对照源数据与最终图中的类别、系列、缓存和标签，核验百分比、合计与派生指标；舍入容差根据显示精度设置，不能凭固定误差百分比放行。检查绘图区、轴界、刻度、标签重叠及异常点。图表结构合法但数值错误，仍不合格。

若使用PptxGenJS，核对已安装版本的图表类型、轴定义和标签位置；堆叠图与组合图尤其需要实际导出检查。源码级类型/结构检查、数值对照和目标应用渲染分别做。`audit_pptx.py`仅统计原生图表数量，不校验其数据、缓存或工作簿一致性。

方法来源：ppt-master当前executor-chart的数据到几何规则、PptxGenJS原生图表能力，以及PPTAgent将内容、设计和连贯性分开评估的思路。
